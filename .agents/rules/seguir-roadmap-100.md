# DIRETIVA OBRIGATÓRIA DE CONTINUIDADE DO SISTEMA CONECTAR

Toda vez que uma nova conversa for iniciada, a sessão for retomada ou o usuário enviar mensagens como "continuar", "continue", "prossiga" ou mensagens em branco:

1. **SEMPRE** consulte o arquivo `ROADMAP_100.md` na raiz do projeto.
2. Identifique a primeira tarefa não concluída (marcada com `[ ]`).
3. Execute o desenvolvimento completo da tarefa (backend + frontend).
4. Verifique o funcionamento.
5. Marque a tarefa como concluída `[x]` no `ROADMAP_100.md`.
6. Avance sequencialmente pelas tarefas até atingir 100% de completude em todos os 19 módulos.
